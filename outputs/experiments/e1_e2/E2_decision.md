# E2. Решение о выборе семейства модели

Правило объявлено в коде e2_compare.py (DECISION_RULE, decide) до просмотра валидационной части; файл сформирован скриптом автоматически. Валидационная, калибровочная и тестовая части при выборе не открывались.

## Правило

1. Кандидаты — модели, недоминируемые по Парето по четырём осям: risk при охвате 0,70 (меньше лучше), AURC (меньше лучше), стандартное отклонение ROC-AUC по внешним фолдам (меньше лучше), медианное время обучения одной модели (меньше лучше).
2. Лидер — кандидат с минимальным risk при охвате C0 = 0,70 (точечная оценка, среднее по 5 повторам); при равенстве — меньший разброс ROC-AUC по фолдам; затем меньшее время обучения.
3. Неотличимые от лидера — кандидаты, у которых 95% интервал парного бутстрепа по звёздам для разности risk@0,70 (модель минус лидер) включает 0.
4. Если неотличимых (включая лидера) больше одного, выбирается самая простая по порядку: логистическая регрессия < Random Forest < XGBoost < LightGBM < SVM < MLP < ансамбль XGBoost. Иначе выбирается лидер.

## Результат

Недоминируемые: Логистическая регрессия (L2), LightGBM, MLP (компактная).

Лидер по risk@70%: MLP (компактная).

Неотличимы от лидера по парному интервалу risk@70% (среди недоминируемых, включая лидера): LightGBM, MLP (компактная).

**Выбрано: LightGBM.**

Обоснование: лидер (MLP (компактная)) статистически неотличим по risk@70% от других недоминируемых моделей, поэтому по правилу выбирается самая простая из них.

Решение после коммита не меняется; результаты валидационной части (п. 3) и последующих шагов только описываются.
