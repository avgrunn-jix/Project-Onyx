СО ROC-AUC по фолдам — стандартное отклонение ROC-AUC по 5 внешним фолдам внутри повтора, усреднённое по 5 повторам. Охват C: доля принятых сигналов с наибольшей уверенностью max(p, 1−p), класс по порогу 0,5, при равной уверенности порядок по signal_id; число принятых — ceil(C·n). AURC — среднее риска по всем охватам k/n, AUGRC — среднее доли ошибок среди всех сигналов (охват × риск). Память: psutil не установлен, поэтому «н/д».

Ансамбль XGBoost (текущая система): гиперпараметры из 3_demo_pipeline.py без подбора — fit_bootstrap_ensemble (n_estimators=60, max_depth=4, learning_rate=0.08, scale_pos_weight = отношение классов), 20 моделей по формуле min(20, max(5, 2·n)) из train_and_eval_pipeline, бутстреп по звёздам; предобработка get_ml_pipeline (медиана, log1p(max(x, 0)), RobustScaler). Межмодельный разброс s на внекорзинных сигналах: среднее 0,079, медиана 0,031.
